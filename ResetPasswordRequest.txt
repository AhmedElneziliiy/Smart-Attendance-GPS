===================================================================
EASIEST SOLUTION: Use Change Password Endpoint (NO TOKEN REQUIRED!)
===================================================================

METHOD 1: Using cURL (Command Line)
-----------------------------------
curl -X POST "https://your-api-url/api/auth/change-password" ^
  -H "Content-Type: application/json" ^
  -d "{\"email\":\"admin@example.com\",\"newPassword\":\"Admin@123\"}"


METHOD 2: Using Postman
-----------------------
1. Open Postman
2. Create a new POST request
3. URL: https://your-api-url/api/auth/change-password
4. Headers:
   - Content-Type: application/json
5. Body (raw JSON):
{
  "email": "admin@example.com",
  "newPassword": "Admin@123"
}
6. Click Send


METHOD 3: Using PowerShell
---------------------------
$body = @{
    email = "admin@example.com"
    newPassword = "Admin@123"
} | ConvertTo-Json

Invoke-RestMethod -Uri "https://your-api-url/api/auth/change-password" `
  -Method Post `
  -ContentType "application/json" `
  -Body $body


METHOD 4: Using Browser (if you have a frontend)
-------------------------------------------------
Just create a simple HTML file and open it in browser:

<!DOCTYPE html>
<html>
<body>
  <h2>Reset Admin Password</h2>
  <button onclick="resetPassword()">Reset Password</button>
  <div id="result"></div>

  <script>
    async function resetPassword() {
      const response = await fetch('https://your-api-url/api/auth/change-password', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          email: 'admin@example.com',
          newPassword: 'Admin@123'
        })
      });

      const result = await response.text();
      document.getElementById('result').innerHTML = result;
    }
  </script>
</body>
</html>


REPLACE "your-api-url" WITH YOUR ACTUAL API URL:
- Local development: https://localhost:7192
- Production: Your production URL

After resetting, login with:
Email: admin@example.com
Password: Admin@123
